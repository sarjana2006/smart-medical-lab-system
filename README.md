# Smart Medical Lab Test Booking, Report & Follow-up Management System

## Project Overview
A patient-centric platform that connects patients and medical laboratories in a single workflow. The system helps users book lab tests, track sample collection, access digital reports, compare test results, and manage follow-up activities.

## Problem
Existing laboratory systems mainly focus on test booking and report delivery. Patients often face difficulties in tracking reports, comparing previous results, and remembering follow-up tests.

## Main Workflow
Book → Collect → Track → Get Report → Compare → Follow-up → Book Next Test

## Key Features

### Patient Module
- Patient registration and login
- Search and book laboratory tests
- Select lab visit or home sample collection
- Track sample status
- View and download reports
- Compare previous and current test results
- Manage follow-up reminders

### Laboratory Admin Module
- Manage laboratory details
- Add and manage tests
- Manage prices and available slots
- Handle bookings
- Update sample status
- Upload reports

## Technology Stack
- Java
- Spring Boot
- MySQL
- REST APIs
- HTML, CSS, JavaScript
